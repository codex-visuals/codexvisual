# CodexVisual ⚡

Кастомный клиент для Minecraft 1.21.4 — ClickGUI, настраиваемый HUD, косметика и визуальные эффекты.

## 📥 Скачать
Кнопка на сайте: https://codex-visuals.github.io/codexvisual/

Прямая ссылка на jar:
https://codex-visuals.github.io/codexvisual/CodexVisual-1.21.4-9.22.4.jar

## ✨ Возможности
- **ClickGUI** — меню модулей прямо в игре
- **Настраиваемый HUD** — FPS, координаты, пинги, арсенал
- **Косметика** — плащи и персонализация персонажа
- **Визуальные эффекты** — улучшенная картинка
- **Автозаход** — сам подключается к серверу при запуске

## 📦 Установка
1. Установи Fabric Loader для 1.21.4 — fabricmc.net/use/installer
2. Скачай Fabric API для 1.21.4 — modrinth.com/mod/fabric-api
3. Закинь оба jar в папку %appdata%\.minecraft\mods
4. Запусти игру с профилем Fabric
