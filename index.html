Частые вопросы

 

Это чит / читерский клиент?

Нет. CodexVisual — визуальный клиент: мечи, косметика, интерфейс и эффекты. Он не даёт игровых преимуществ и не вмешивается в механику серверов.

Безопасно ли скачивать?

Файл лежит в открытом репозитории на GitHub — можно посмотреть содержимое и историю. Кнопка «Скачать» ведёт ровно на этот файл.

Как обновить до новой версии?

Скачай свежий jar с этого сайта (кнопка сверху) и замени им старый файл в папке mods. Ничего переустанавливать не нужно, настройки сохраняются.

Игра не запускается / крашится

Проверь, что стоят именно Minecraft 1.21.4, Fabric Loader и Fabric API для 1.21.4, и Java 21. Если не помогло — напиши в Issues на GitHub, приложив лог игры.
